改动会发生什么

· 面板令牌：立即生效（当前浏览器需要用新令牌重新登录），同时写入 compose。
· RCON 密码：写入 server.properties + compose 的 mc-server.RCON_PASSWORD 与 mcai-panel.MC_RCON_PASSWORD。因为环境变量变更必须重建容器， 之后请在宿主机执行 docker compose up -d mc-server mcai-panel。
